# Privacy Policy – GT Clean View

**Last updated: August 18, 2026**

GT Clean View is a browser extension for Galactic Tycoons that modifies the visual appearance of the game by hiding selected game-related graphics.

## Data Collection

GT Clean View does not collect, transmit, sell, or share personal data.

The extension does not collect:

- Personally identifiable information
- Health information
- Financial or payment information
- Authentication information
- Personal communications
- Location data
- Web browsing history
- User activity data
- Website content for collection or transmission

## Local Settings

GT Clean View stores the user's Clean View preference locally in the browser using `localStorage`.

This preference only determines whether Clean View is enabled or disabled. It is stored locally on the user's device and is never transmitted to the developer or any third party.

## Website Access

GT Clean View runs only on:

`https://g2.galactictycoons.com/`

The extension accesses the page solely to modify its visual presentation and to provide the Clean View toggle.

The extension does not:

- Modify or transmit game data
- Access the game's backend or APIs
- Monitor user activity
- Track browsing history
- Send webpage content to external servers
- Use analytics or advertising services

## Third-Party Services

GT Clean View does not use third-party services for analytics, advertising, tracking, or data processing.

## Data Sharing

No user data is sold, transferred, or shared with third parties.

## Changes to This Privacy Policy

This privacy policy may be updated if the functionality of GT Clean View changes. Any changes will be published on this page.

## Contact

For questions, feedback, or concerns regarding this privacy policy or GT Clean View, please open an issue in the project's GitHub repository.

## Disclaimer

GT Clean View is an unofficial community project and is not affiliated with, endorsed by, or sponsored by the developers or operators of Galactic Tycoons.
